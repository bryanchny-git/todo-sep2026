# Plan for a To Do app

Specifications
1. simple to do app. No frills. basic
2. It should run in a browser
3. Add a task, mark it complete/incomplete, delete a task
4. Each task has a priority (low/medium/high); tasks are sorted by priority
5. Dark mode toggle, with preference remembered between visits
6. Tasks persist in the browser (localStorage) — no backend/server, no accounts

Technology
- Plain HTML, CSS, and JavaScript (no frameworks, no build tools)
- Data stored client-side via localStorage
