# CLAUDE COMMANDS

/clear - to start a new conversation (clear previous memory/chat history)

/compact - compress the context memory and reduce it to a summary to take forward. It frees up the context window, and reduces the cost of tokens immediately. 

/usage - to view the current usage in context, 5 hour limit, and weekly limt - how much is left and use up

/init - to initialize the project and create CLAUDE.md file - this is standing instructions to Calude for any coding tasks. You can create one for the project, one for any subfolder in a project.
